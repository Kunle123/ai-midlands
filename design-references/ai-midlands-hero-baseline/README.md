# AI Midlands hero baseline

This is a deliberately static HTML/CSS design reference for Cursor.

## Purpose
- Establish exact composition and visual grammar before React implementation or animation.
- Familiar business artefacts remain the subject: email, spreadsheet, CRM, website assistant and invoice.
- No animation is included.
- Cursor should port this structure faithfully rather than redesigning it.

## Files
- `hero-baseline.html`
- `hero-baseline.css`
- `approved-reference.png` — the approved visual reference supplied in the conversation.

Open `hero-baseline.html` directly in a browser.

## Important
This prototype intentionally preserves the approved reference composition, including the small central AM node. If the next design decision is to remove that node, do it as a single reviewed change rather than allowing Cursor to reinterpret the whole composition.
